<b>为什么会制定这个书单？</b>

这个书单的阅读跨度从2023年到2026年，书单的诞生完全是来自我作为一个关注技术与社会的研究者私人阅读偏好。这个书单的诞生过程中几乎穿越了AI技术高速发展时期的“文科生兴废论”——从生成式AI阴影下的“文科生无用论”，到AI幻觉、技术极化、活人感丧失、机器霸权等的“文科生价值论”，这种被情绪和叙事左右的舆论腔调，让我认为，作为文科生，有必要建立一种对AI的独立认知。



在一种“AI是文科生的黄金时代”补偿性叙事渲染下，硅谷的AI公司开始广泛聘请哲学家进入公司任职，面对公众对AI发展的担忧，他们好像有意去修复被机器肢解得支离破碎的AI人文故事，但又好像试图为自身的AI项目去一个建立自主可控的哲学意象，以摆脱算法的冷血与无情形象。



当自媒体与企业公关通稿充斥着一片底细不清的论文数据和不明觉厉的参数，似乎作为文科生就只能等待被塞入一种随便是什么都可以的解释，然后在给定的答案下学习如何应用AI、批判AI。



这种情况必须得到改变，于是有了这个书单。不求完美，但求可以让文科生对AI具备一种更为自主的思考框架，而不至于被震惊体们所击倒或俘虏。



<b>为什么我觉得是“文科生的AI书单”？</b>

很显然，在技术狂飙时代，“文科生”的形象显得十分弱势，“不懂技术”的形容让人误以为他们就不配活在这个技术优先的时代……但是，从历史上，技术的社会价值、历史地位、发展走向等等，最终都需要靠“文科生”来进行定义和校准，在没有北斗星的黑夜中，通过批判与思辨来获得对技术的解释。否则，刀，永远都只是凶器，而不是正义的武器。



“文科生”面对技术不只有顺从或承担作为一个阐释者的角色，而需要在政治形势、社会结构、技术走势的混沌中，建立一种重新审视技术价值的坐标，在AI风声鹤唳的产业浪潮里，去筛选、擦拭、磨砺那些真正的不褪色的价值。而不是在AI技术能力的纵容下，成为一个熟练的AI slop生产者。



这个书单就是帮助文科生重建面对技术时代的自信。文科生面对AI并不只有言说、阐释以及传播的责任，在众声喧哗中指出AI的“是”与“不是”更加重要。



<b>这个书单的选择标准是什么？</b>

这个书单的选择主要遵循了以下四个维度的标准：

一是核心问题聚焦在算法、平台、数据；通过对算法本质、平台运行、数据应用等进行解析，解剖AI时代的发展真相；

二是主要内容落脚在理论、模式、案例；通过理论的解读，配合相关的数据治理与应用模式，结合全球不同地区的案例进行解读；

四是关键对象围绕个体、企业、国家；通过对个人选择、企业发展以及国家命运的分析和解读，不断探索和逼近AI时代的真相；

五是重点关注领域在战争、生活、爱情；通过对未来战争的走向、人类生活的算法冲击以及机器和算法介入亲密关系与情感选择之后，我们能做什么以及必须面对什么……

1、《AI SNAKE OIL：what artificial intelligence can do，what it can't，and how to tell the difference》

如果我推荐的所有书你都没时间读，这本书一定要读。这本书叫“人工智能蛇油”或“人工智能万金油”，意思就是媒体、专家以及公司的AI叙事在将人工智能粉饰为“无所不能”的圣体，但我们必须知道，AI能干什么、不能干什么，以及为什么？

2、《Technofeudalism：what killed capitalism》

这本书是希腊前财长雅鲁法克西的手笔，跟另一个德国作者写的同名书有异曲同工之妙。技术封建主义主要是关于作者对资本主义“末路”的思考，从他的角度来看，它认为平台经济不过是一种封建主义的变种，是圈地收租的套路，不是资本主义的高级形式，而是杀死资本主义的自由市场、利润和竞争等的东西。

3、《Filterworld：how algorithms flattened culture》

这是纽约时报专栏作者凯尔·卡查伊的作品，主要就是讲当AI和算法剥夺和绑架了人类的审美能力与创作激情，“品味”就是人类最后抵抗AI时代的东西。“策展人”是一个未来需求的职业，这本书比较适合自媒体人和个人创作者。

4、《Feeding the machine：the hidden human labor powering AI》

“喂养机器”主要揭示了在人工智能的“智慧”繁荣的背后，其背后是一套亘古未变的永恒的殖民主义逻辑。作者认为，硅谷的大模型和智能体的能力如何如何突出，最终都是依靠南方国家的肮脏不堪的工作环境下的低端劳动力的数据标注工作来维持的。

5、《The Technological Republic：hard power，soft belief，and the future of the WEST》

这是哲学家、帕兰提尔的CEO亚历克斯·卡普的著作，“技术共和国”本质上包含了新一代硅谷科技资本与创业者在二战后逐步形成，在911事件后茁壮成长的“军事科技复合体”以及背后的技术民族主义。他们认为在美国利用强大的军事能力保卫硅谷岁月静好的事实之下，他们自己有责任为美国再次强大来承担“技术救国”的责任……

6、《algorithmic institutionalism》

这是一种优雅、精美的关于算法理论的书籍。作者的文笔优美而富有张力，推荐研究算法的文科生必读。作者的突出观点是——算法是一种在社会环境中不断演化的人工合成制品。

7、《AI，AUTOMATION,AND WAR》

如果你想了解未来的战争以及无人机、自动化武器如何影响国家之间的冲突，请阅读这本书。

8、《Love Machine》

爱情机器，作者希望探讨的是，当爱情成为一种可定制化的订阅服务，那么爱情中充满了犹豫、沮丧、失而复得的复杂情感还会存在么？我们还会像AI前时代那样期待爱情降临么？

9、《IF…THEN》

略。

10、《TECHAGNOSTIC》

最后这本书叫“科技不可知论”，这本书探讨的是科技是如何一步步变成了宗教。作者对比了科技与宗教在外部形式、运作方式以及表现路径上的相似之处，提倡我们应该对科技进行祛魅，要勇敢地去选择和直面，而不是回避、拒绝或选择中立。

<b>最后，希望每一个文科生都对扑面而来的AI时代保持信心、保持敬畏、保持勇敢。</b>
